# 🌿 LAMBERT • Clinical Dermatology & Aesthetic Medicine

A high-performance, medical-grade website tailored for board-certified dermatologists and modern skin aesthetics clinics. Inspired by the refined, minimalist balance of Hostinger's Lambert template and elevated with bespoke clinical interactions, diagnostic tools, and lead conversion workflows.

![Website Preview](https://images.unsplash.com/photo-1622253692010-333f2da6031d?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features & Highlights

- **Refined Clinical Luxury Aesthetic:** Designed with calming eucalyptus tones, warm champagne gold accents, and editorial typography (`Fraunces` serif + `Plus Jakarta Sans`).
- **Interactive Skin Assessment Quiz:** "Smart Derm Finder" allowing patients to select their concern (Acne, Melasma, Aging, Scar Revision, Hair Thinning) to receive instant clinical recommendations and downtime estimates.
- **Before & After Visual Comparison Slider:** Smooth touch-enabled and mouse-draggable split comparison viewer across multiple clinical case studies.
- **Categorized Treatment Filter:** Dynamic tabbed filtering across Medical Dermatology, Aesthetic Lasers (PicoWay®, Fractional CO2), Injectables (Botox®, Fillers), and Clinical Medi-Facials.
- **Instant Booking & WhatsApp Integration:** Direct modal booking engine that formats patient data into pre-filled WhatsApp consultation requests and automatically generates downloadable `.ics` calendar invites for Apple / Google Calendar.
- **Transparent Tiered Care Packages:** Clear pricing structure for diagnostic evaluations, acne elimination protocols, and annual skin longevity passes.
- **100% Responsive & Accessible:** Fluid layouts optimized for ultra-fast performance across all mobile devices, tablets, and desktop displays.

---

## 🛠️ Tech Stack

- **Core:** Semantic HTML5, Vanilla JavaScript (ES6+)
- **Styling:** Bespoke Vanilla CSS with custom design tokens, responsive breakpoints, and glassmorphism
- **Typography:** Google Fonts (`Fraunces`, `Plus Jakarta Sans`)
- **Hosting:** GitHub Pages / Vercel / Netlify (Zero runtime dependencies, loads in milliseconds)

## 🚀 Local Development

Simply open `index.html` in any web browser:

```bash
# Clone the repository
git clone https://github.com/404existential/lambert-dermatology.git

# Navigate into the project folder
cd lambert-dermatology

# Open index.html directly
start index.html
```
